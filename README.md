# Магнетар

Сайт-визитка: лендинги под ключ, от которых невозможно оторваться.
Всё нарисовано кодом — ни одной картинки на странице.

- `index.html`, `css/`, `js/` — сайт (HTML, CSS, JavaScript, GSAP, Lenis)
- `js/config.js` — адрес формы заявок и юзернейм Telegram-бота
- `backend/` — Google Apps Script: заявки с сайта и бот-анкета в Telegram (инструкция в `backend/README.md`)
- `tools/make-og.ps1` — рисует превью ссылки `og.png`
- `404.html` — страница «затянуло в чёрную дыру»
