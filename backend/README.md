# Заявки и бот-анкета → ваш Telegram

Как это работает:

- **Форма на сайте** → Google Apps Script (`apps-script/Code.gs`) → сообщение вам в Telegram.
- **Бот в Telegram**: клиент нажимает «Обсудить в Telegram» → бот задаёт 7 вопросов
  (бизнес, задача, пакет, что ещё нужно, срок, имя, телефон) → вам приходит готовый бриф.

Токен бота хранится только в настройках скрипта Google и **никогда** не попадает в код сайта.
Всё бесплатно. Настройка — около 15 минут, один раз.

## 1. Создать бота

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя (его видят клиенты), например: `Магнетар — бриф на сайт`.
3. Юзернейм — латиницей и обязательно на `bot`, например `magnetar_brief_bot`.
4. BotFather пришлёт **токен** вида `123456789:AA...`. Никому его не пересылайте.
5. По желанию в @BotFather: `/setuserpic` — аватарка, `/setdescription` — текст
   «Помогу собрать бриф для лендинга за минуту. Оплата — только когда сайт работает».

## 2. Решить, куда приходят заявки

- **Лично вам:** откройте своего бота и нажмите «Старт» (`/start`).
- **В группу:** создайте группу, добавьте туда бота и напишите в группе `/start@юзернейм_бота`.

## 3. Создать скрипт

1. Откройте [script.google.com](https://script.google.com) → «Новый проект».
2. Назовите проект `Магнетар — заявки`.
3. Удалите всё в файле `Код.gs` и вставьте содержимое `apps-script/Code.gs`. Сохраните (Ctrl+S).

## 4. Вставить токен

1. Слева шестерёнка «Настройки проекта» → внизу «Свойства скрипта» → «Добавить свойство».
2. Свойство `TELEGRAM_BOT_TOKEN`, значение — токен из шага 1. «Сохранить свойства скрипта».

## 5. Узнать, куда слать (ID чата)

1. Вернитесь в редактор (`<>` слева). Вверху в списке функций выберите `findChatId` → «Выполнить».
2. Google попросит разрешения: «Проверить разрешения» → ваш аккаунт → «Дополнительные настройки» →
   «Перейти на страницу проекта» → «Разрешить». Предупреждение появляется, потому что скрипт
   ваш личный, а не из магазина — это нормально.
3. Внизу в «Журнале выполнения» появится строка вида `Личка «Имя» → OWNER_CHAT_ID = 123456789`
   (у группы число начинается с минуса).
4. Добавьте в «Свойства скрипта» свойство `OWNER_CHAT_ID` с этим числом (вместе с минусом, если он есть).

## 6. Проверить

Выберите функцию `sendTest` → «Выполнить». Вам в Telegram придёт «Магнетар на связи».

## 7. Опубликовать

1. Вверху справа «Начать развертывание» → «Новое развертывание».
2. Шестерёнка «Выберите тип» → «Веб-приложение».
3. «Запуск от имени»: **Я**. «У кого есть доступ»: **Все**.
4. «Начать развертывание» → скопируйте **URL веб-приложения** (заканчивается на `/exec`).
5. Добавьте в «Свойства скрипта» свойство `WEBAPP_URL` с этим адресом.

## 8. Подключить бота

Выберите функцию `setWebhook` → «Выполнить». В журнале: «Готово! Бот подключён».
Напишите боту `/start` — он начнёт задавать вопросы, а в конце пришлёт вам бриф.

## 9. Вписать адреса в сайт

Откройте `js/config.js` и заполните:

```js
formEndpoint: 'https://script.google.com/macros/s/.../exec', // URL из шага 7
telegramBot: 'magnetar_brief_bot',                          // юзернейм бота без @
```

После этого форма начнёт присылать заявки, а на сайте появятся кнопки «Обсудить в Telegram».

## Если что-то поменяли в Code.gs

«Начать развертывание» → «Управление развертываниями» → карандаш → Версия: «Новая версия» → «Развернуть».
URL при этом не меняется, `setWebhook` запускать заново не нужно.

## Частые вопросы

- **Хочу поменять вопросы бота** — они в начале `Code.gs`, в списке `QUESTIONS`. После правки — новая версия (см. выше).
- **Хочу перенести заявки в группу** — запустите `deleteWebhook`, добавьте бота в группу, напишите там
  `/start@юзернейм_бота`, запустите `findChatId`, поменяйте `OWNER_CHAT_ID`, затем снова `setWebhook`.
- **Токен утёк** — в @BotFather `/revoke` → выберите бота, вставьте новый токен в «Свойства скрипта»
  и снова запустите `setWebhook`.

## Защита от спама

- скрытое поле-ловушка и проверка «форма заполнена быстрее 3 секунд» отсекают ботов;
- с одного контакта — не чаще одной заявки в 2 минуты; со всего сайта — не больше 30 за 10 минут;
- бот принимает запросы только от Telegram (секретный ключ в адресе вебхука) и молчит в группах.
